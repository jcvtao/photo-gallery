# Accessible Photo Gallery

Final project of the [*Interactivity with JavaScript*](https://www.coursera.org/learn/javascript) course by the University of Michigan.

A simple photo gallery built with HTML, CSS, and vanilla JavaScript. Supports both mouse and keyboard navigation, and meets WAVE and W3C accessibility standards.
